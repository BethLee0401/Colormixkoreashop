# Colormixkoreashop

## 購物流程

- 首頁點商品可直接開啟視窗，選尺寸、顏色和數量並加入購物車；關閉後可繼續挑選。
- `cart.html` 使用既有的 Supabase 會員登入與 `create_order_with_payment` RPC 建立訂單。正式啟用前請在測試環境確認 RPC 的庫存扣除、價格重算及付款條件。
- `admin.html` 保留商品上架／下架、原價和尺寸顏色庫存管理。

## 超商取貨（無需物流商帳號）

結帳時點「查詢並填入全家門市」或「查詢並填入 7-ELEVEN 門市」，在新分頁查看品牌官方門市查詢頁。顧客返回結帳視窗手動填入門市名稱、店號及選填地址，按「使用這間門市」後，門市資料即帶入此筆訂單的寄送地址。未選門市不能送出超商取貨訂單；切換寄送方式會清除先前選擇。店號僅檢查格式，店名與店號仍須人工核對。

這是免申請的手動選店流程；官方查詢頁不會自動把選店結果回傳本站，也不會自動建立物流單。若日後需要自動選店與回傳，再申請物流服務並在隔離環境測試其地圖介面。現有 Supabase 下單 RPC 仍須以測試帳號和測試資料驗證後才能合併正式分支。
